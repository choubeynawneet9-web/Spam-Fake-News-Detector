Is this message spam?

Paste a text message and a small machine-learning model will tell you whether it looks like spam, and which words gave it away.

Or try an example:

How it works

  1. Collect labelled messages.
    The project uses the SMS Spam Collection, about 5,500 real messages already marked as spam or genuine (ham).
  2. Turn text into numbers.
    Each message is split into words. In the full project, TF-IDF gives more weight to words that are distinctive, such as “claim”, and less to everyday words, such as “the”.
  3. Learn which words signal spam.
    A Naive Bayes classifier counts how often each word appears in spam and in genuine messages.
  4. Score a new message.
    Every word in a new message pushes the verdict toward spam or toward genuine. The total decides the label.

The checker above is a lightweight version that runs entirely in your browser. It trains on about 50 short example messages using word counts, so it can be fooled. The full model, trained on the complete dataset with Python and scikit-learn, is far more accurate.

Spot spam yourself

  • Urgency. “Act now” and “last chance” are meant to stop you from thinking.
  • Prizes you never entered for. A win you did not enter for is almost always a trap.
  • Unknown links. Do not tap links from numbers you do not know.
  • Requests for an OTP, a password or card details. Real banks never ask for these by message.
  • Pressure to pay a small fee. Fake delivery and refund messages often start this way.
