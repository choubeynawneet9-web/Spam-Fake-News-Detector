# Spam-Fake-News-Detector
SMS Spam Detector: a machine-learning web app that tells whether a text message is spam or genuine and highlights the words that gave it away. Built for Mini Project 1 (AI-Based Application Development) with Python, scikit-learn, TF-IDF and Naive Bayes, plus a live in-browser demo. Paste a message to test it, learn the warning signs of scam texts.
